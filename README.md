One number, digits only: the honest count of browser tabs open at build time. `main.ts` writes that number to `/output/entry.txt` and nothing else.

## Run it

```sh
node main.ts
```

## Why 127

127 is the count I actually had open when I built this: several windows of research tabs, documentation, half-read articles, videos queued for later, and the "I'll close these tomorrow" pile that never gets closed. It is odd and unrounded — a counted number, not a guessed one — high enough to surprise against the field's likely 20–60 cluster, and still a count a real tab hoarder could honestly have open right now, not a shock figure picked for effect. Three digits, three bytes: small on the page, large in the browser.
